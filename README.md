# 报价计算器 PWA

## GitHub Pages
1. 新建 GitHub Repository，例如 `quote-calculator`。
2. 上传本目录全部文件到仓库根目录。
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save。
4. 打开生成的 `https://你的用户名.github.io/quote-calculator/`。
5. iPhone Safari 打开 → 分享 → 添加到主屏幕 → 开启“作为网页 App 打开”。
